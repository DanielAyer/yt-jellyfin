▶ YT → Jellyfin

First-Run Setup

yt-jellyfin needs to know where your media library lives. You can import this automatically from Jellyfin, or configure it manually.

1

Enter your Jellyfin URL

The address Jellyfin is running on. Usually this is the same machine.

2

Get your Jellyfin API key

In Jellyfin, go to Dashboard → API Keys and create a new key for yt-jellyfin.

3

Select your YouTube library folder

Choose the Jellyfin library where YouTube content should be stored.

The selected folder will be used as LIBRARY_ROOT. The database will be stored at LIBRARY_ROOT/.ytjf.db.

1

Library root folder

The folder where downloaded videos will be stored, organized as LIBRARY_ROOT/ChannelName/video.mp4. Must already exist on disk.

2

Database path

Where the app's SQLite database file should live. Keeping it inside your library folder means it travels with the drive.
