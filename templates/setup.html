▶ YT → Jellyfin

First-Run Setup

yt-jellyfin needs to know where your media library lives. Import automatically from Jellyfin, or configure manually.

1

Jellyfin server URL

The address your Jellyfin server is running on. If Jellyfin is on a different machine, enter its IP or hostname. You can also set JELLYFIN_URL in your .env file.

2

Jellyfin API key

In Jellyfin, go to Dashboard → API Keys and create a new key for yt-jellyfin. Paste it below.

3

Select library folder

Choose which Jellyfin library to use for YouTube content.

YouTube subfolder:

1

Library root folder

Where downloaded videos will be stored, organized as LIBRARY_ROOT/ChannelName/video.mp4. The folder will be created if it doesn't exist.

2

Database path

Where the SQLite database file will live. Keeping it inside your library folder means it travels with the drive.

Restart the service to activate:

sudo systemctl restart yt-jellyfin
